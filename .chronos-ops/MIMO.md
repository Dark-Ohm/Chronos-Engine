## ЗАДАНИЕ M-2 — llama-bench: добавить turbo/kvarn в whitelist типов

### Контекст
`llama-bench` — единственный из наших CLI-инструментов, который НЕ умеет
`--cache-type-k/-v turbo*` или `kvarn*` (в отличие от `llama-server`,
`llama-cli`, где парсинг типов идёт через общий `common/arg.cpp`
whitelist). Найдено при приёмке G-3: `llama-bench` не смог сравнить
turbo3/kvarn4 против f16 в одинаковых условиях, пришлось обходить через
server-timings. Небольшая, изолированная правка.

### Что сделать
1. Найди `ggml_type_from_name` в `tools/llama-bench/llama-bench.cpp`
   (ориентир из G-3-отчёта — около строки 478, сверь по факту, номер мог
   сдвинуться). Сейчас список: `f16,bf16,q8_0,q4_0,q4_1,q5_0,q5_1,iq4_nl`.
2. Сверь с полным списком типов, которые ПРИНИМАЕТ `common/arg.cpp` для
   `--cache-type-k/-v` (там уже есть turbo2/3/4_0, turbo2/3/4_tcq,
   kvarn2/4/6/8 и т.д. — найди точный список, не выдумывай имена).
3. Добавь адресно недостающие имена в `ggml_type_from_name` внутри
   `llama-bench.cpp`, тем же паттерном, что уже там есть (`if (s ==
   "...") return GGML_TYPE_...;`). Порядок и стиль — как в существующем
   коде.
4. Проверь: `llama-bench` использует этот тип только для `-ctk`/`-ctv`
   параметров бенчмарка — подмена типа не должна затрагивать ничего
   другого в файле (не расширяй скоуп).

### Границы
- Файл: только `tools/llama-bench/llama-bench.cpp`.
- Не трогай `common/arg.cpp` (там список уже полный и правильный — ты
