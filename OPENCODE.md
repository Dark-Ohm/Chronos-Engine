# OPENCODE — Рабочий журнал

Этот файл пишет ТОЛЬКО Архитектор. Файл держит ТОЛЬКО текущее задание —
история заданий и приёмок в `git log -- OPENCODE.md`. Твои отчёты — ТОЛЬКО
в `opencode-report.md` (перезаписывай под каждое задание: номер, diffstat,
пропущенное с причинами, вопросы).

## ПРАВИЛА ИСПОЛНИТЕЛЯ (обязательны)

1. **Нет разрешения на инструмент — значит НЕТ.** Уперся в запрет — СТОП,
   одна строка в отчёт: какой инструмент нужен и для чего.
2. **Сборку и тесты запускает Архитектор.** Твоя зона: правка файлов строго
   по заданию + отчёт «готово к сборке». cmake/ctest/gdb не трогать.
3. **Скоуп задания — граница.** Выход за него — сначала строка в отчёте,
   потом (после добра) правка. Молчаливый выход за скоуп = откат.
4. Не коммитить. Коммитит Архитектор после приёмки.
5. **Никаких regex/sed-замен по нескольким вхождениям разом в C++-коде.**
   Каждое вхождение читай в полном контексте охватывающего блока и правь
   вручную.
6. **«Взять файл целиком из донора» ЗАПРЕЩЕНО** — портировать только
   адресные правки.
